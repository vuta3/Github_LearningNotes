# GitHubで新しいリポジトリを作る方法

## 手順1：New repositoryを開く
画面右上の「＋」をクリックし、「New repository」を選択<br>

## 手順2:General（ジェネラル）を設定する
Generalは、リポジトリの基本情報を設定する場所<br>

### Owner（オーナー）
所有者という意味<br>
このリポジトリを、どのGitHubアカウントの所有物として作成するかを選ぶ<br>
vuta3に設定<br>
会社やチームで使う場合、Ownerをどうするか確認<br>

### Repository name
リポジトリの名前、ほとんどの場合これから作るプログラムの名前

### Description（ディスクリプション）
リポジトリの簡潔な説明文<br>
細かいことはREADMEで書く<br>

## 手順3:Configuration（コンフィギュレーション）を設定する
公開範囲や初期ファイルを設定する場所<br>

### Choose visibility（チューズ　ビジビリティ）
公開範囲を選択するって意味<br>

### Public（パブリック）
公開するって意味<br>

### Private（プライベート）
非公開にする設定<br>
自分とアクセスを許可した人だけが閲覧できる<br>

## 手順4:Add README
READMEを追加する<br>

## 手順5:Add .gitignore
.gitignoreを追加する<br>
