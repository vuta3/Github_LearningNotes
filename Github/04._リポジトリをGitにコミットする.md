# リポジトリをステージングしgitにコミットする！
自分のPCで作成したプログラムをGitHub上へコピーする<br>

## 手順1:PowerShellでGitに反映したいリポジトリを開く
cd 反映したいリポジトリ<br>

## 手順2:リポジトリの状態を確認
git statusを実行<br>
modified:フォルダ名　=　指定されたフォルダで何か変更があった<br>
Untracked files:フォルダ名　=　指定されたフォルダを新規作成した<br>

## 手順3:変更をステージング
以下を実行<br>
git add .<br>
gitでは、対象をいきなり保存せず「対象をコミット対象として選ぶ（ステージング）」→「gitで追加（コミット）」って手順をとる<br>
git add .は今私がいるディレクトリとその配下ぜんぶステージングって意味<br>

## 手順4:履歴として保存する
git commit -m "変更内容"<br>
こういうの残しとかないと後で揉めたとき責任逃れできない<br>

## 手順5:内容をgitに反映する
以下を実行<br>
git push<br>
