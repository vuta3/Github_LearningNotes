# クローンとは？
GitHub上のリポジトリを、変更履歴ごと自分のPCへコピーする操作<br>
Gitの管理情報も一緒にコピーされる<br>

## 手順1:クローンするリポジトリを開く
GitHubで、PCへコピーしたいリポジトリを開く<br>

## 手順2:リポジトリのURLをコピーする
画面右上付近の緑色の 「Code」ボタンを押す<br>
「HTTPS」を選んで、URLの右側にあるコピーを押す<br>

## 手順3:PC側のフォルダに保存
C:\Projects　等に保存<br>

## 手順4:PowerShellで以下のコマンドを実行
git clone https://github.com/オーナー名/リポジトリ名.git<br>

## 手順5:ターミナル内で作成したフォルダに移動
cd リポジトリ名<br>

## 手順6:dirコマンドを実行し以下の結果が表示されれば成功!!
.gitignore<br>
LICENSE<br>
README.md<br>
