# Javaプロジェクトのフォルダ構成

```text
リポジトリ名/
├─ src/
│  └─リポジトリ名.java
├─ out/
├─ .git/
├─ .gitignore
├─ LICENSE
└─ README.md
```

※┣や└は罫線素片（けいせんそへん）は「けいせん」または「きごう」と入力したら出せる<br>

## プロジェクトルートとは？
そのプロジェクト全体の一番上にあるフォルダ<br>
大体は作成したいプログラムの名前(vuta_maskなど)<br>

## src（ソース）とは？
ソースコードを保存するフォルダ<br>
ソースコードとは、コンピューターに「こういう風に動いてほしい」と伝えるための指示書<br>
Javaの場合は拡張子が.javaになる<br>

## resources(リソーシズ)
リソース（画像、アイコン、設定ファイルなど）、つまりjavaコード以外の使用ファイルを保存<>br>

## test（テスト）
プログラムの動作を自動的に確認するテストコードを保存<br>

## docs(ドックス)
ドキュメント、設計書や詳しい説明資料を保存するフォルダ<br>

## bin(ビン)またはout(アウト)
binはバイナリ、outはアウトプット<br>
Javaソースコードをコンパイルした結果を保存するフォルダ<br>
javaをコンパイルすると拡張子が.classになる<br>

## build(ビルド)
コンパイル結果、作成途中の配布用ファイルを保存するフォルダ<br>

## target（ターゲット）
MavenというJavaのビルドツールがコンパイル結果を保存するためのフォルダ<br>

## .git（ドットギット）
Gitが変更履歴やリポジトリの設定を保存する隠しフォルダでgit cloneを実行すると自動的に作成される<br>

# ターミナルでのフォルダの作成手順

cdで作業フォルダ内に移動<br>
mkdir 作りたいフォルダ<br>
