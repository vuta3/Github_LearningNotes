# Javaプロジェクトのフォルダ構成

```text
├─ src/
│  └─ VutaMask.java
├─ .gitignore
├─ LICENSE
└─ README.md
```

※┣や└は罫線素片（けいせんそへん）は「けいせん」または「きごう」と入力したら出せる<br>

## プロジェクトルートとは？
そのプロジェクト全体の一番上にあるフォルダ<br>
大体は作成したいプログラムの名前(vuta_maskなど)<br>

## src（ソース）とは？
ソースコードを保存するフォルダ<br>
ソースコードとは、コンピューターに「こういう風に動いてほしい」と伝えるための指示書<br>
Javaの場合は拡張子が.javaになる<br>
